Ansible is a powerful automation tool that simplifies the management of systems and applications. This guide will help you get started with Ansible, covering installation, basic concepts, and your first playbook.

## What is Ansible?

Ansible is an open-source automation tool that allows you to automate tasks such as configuration management, application deployment, and orchestration. It uses a simple, human-readable language (YAML) to define automation tasks.

**Overview:**  
This lesson is your starting point for learning Ansible. We’ll guide you through setting up your environment, including the control node and managed nodes. You’ll learn how to install Ansible, configure SSH for passwordless authentication, and create an inventory file to manage your nodes.

### **Ansible 101 - Node Setup for Running Playbooks (Lesson 1)**

**Overview:**  
This lesson is your starting point for learning Ansible. We’ll guide you through setting up your environment, including the control node and managed nodes. You’ll learn how to install Ansible, configure SSH for passwordless authentication, and create an inventory file to manage your nodes.

**What You’ll Learn:**

- How to install Ansible on your control machine (Linux/Unix-based systems).
    
- Setting up SSH keys for secure and passwordless communication between nodes.
    
- Creating and organizing an inventory file to define your managed nodes.
    
- Running a simple playbook to test your setup.
    

**Prerequisites:**

- Basic knowledge of Linux command line.
    
- Access to at least two machines (one control node and one managed node).
